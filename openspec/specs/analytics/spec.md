## ADDED Requirements

### Requirement: 学习日历

系统 SHALL 展示年度学习日历热力图。

- 展示过去 365 天的学习活跃度
- 每天一个格子，颜色深浅表示学习量
- 数据从后端 API 获取

#### Scenario: 日历正常显示

- **GIVEN 用户已登录且有学习记录
- **WHEN** 查看学习数据页面
- **THEN** 显示年度日历
- **AND** 有学习活动的日期显示对应颜色

#### Scenario: 日历无数据

- **GIVEN** 用户没有学习记录
- **WHEN** 查看学习数据页面
- **THEN** 日历格子全部为灰色

---

### Requirement: 成就系统

系统 SHALL 展示用户已解锁和待解锁的成就徽章。

- 已解锁成就显示完整徽章 + 解锁时间
- 未解锁成就显示灰色占位 + 进度
- 数据从后端 API 获取

#### Scenario: 显示成就列表

- **GIVEN** 用户已登录
- **WHEN** 查看学习数据页面
- **THEN** 显示成就徽章网格
- **AND** 已解锁和未解锁成就分别标识
